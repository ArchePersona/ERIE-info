# ERIE Documentation

This directory contains the public documentation for ERIE — the Epistemic Reasoning & Investigation Engine.

ERIE's implementation is proprietary. These documents describe the supported external concepts, integration boundary, and evaluation model without exposing internal source code or deployment details.

## Documents

### [Integration Overview](INTEGRATION.md)

The external ERIE model for applications and evaluators: retrieval requests, evidence, provenance, evidence sets, reasoning requests, results, and the stability boundary for integrations.

### [Evaluation Guide](EVALUATION.md)

A behavior-focused framework for testing grounding, unsupported claims, provenance, evidence isolation, contradiction handling, traceability, and repeatability.

## Authoritative interfaces

The documents in this repository explain ERIE's public concepts. For an active integration, the deployed API schema, authentication requirements, endpoint documentation, and access terms supplied with ERIE access are authoritative.
