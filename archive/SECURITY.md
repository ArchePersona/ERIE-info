# Security Policy

## Scope

This repository contains public information and documentation for ERIE. It does not contain the proprietary ERIE implementation, production credentials, private deployment configuration, or customer data.

Security reports concerning ERIE itself, its API, authentication, authorization, data handling, or a deployed ERIE service should be reported privately rather than opened as a public issue.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public GitHub issue, discussion, pull request, or other public channel.

Send a private report to the repository owner with:

- a concise description of the issue
- the affected ERIE surface or service
- reproduction steps, when available
- the potential impact
- any relevant logs or request identifiers with secrets removed

Do not include API keys, access tokens, credentials, private evidence, customer data, or other sensitive information in a report unless a secure exchange method has been established.

## Responsible testing

Evaluation access does not authorize destructive testing, denial-of-service activity, credential attacks, access to data belonging to other users, or attempts to bypass contractual or technical access controls.

Good-faith reports will be reviewed and handled privately.
