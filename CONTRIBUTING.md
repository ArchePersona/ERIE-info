# Contributing

ERIE is proprietary software and is not developed as an open-source project. This repository exists to publish ERIE's external concepts, evaluation guidance, and integration information.

Source-code contributions to ERIE are therefore not accepted through this repository.

## Documentation corrections

Clear factual errors, broken references, and documentation ambiguities may be reported through the repository's issue tracker when they do not involve confidential, security-sensitive, or proprietary information.

Please keep reports narrowly scoped and include the document, section, and proposed correction.

## Security issues

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Product and integration requests

Requests involving API access, commercial licensing, private implementation details, or evaluation arrangements should be directed to the repository owner rather than submitted as code contributions.

Submitting material to this repository does not grant access to ERIE source code and does not alter ERIE's proprietary licensing terms.
